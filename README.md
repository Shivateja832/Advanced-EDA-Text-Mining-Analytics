# Advanced-EDA-Text-Mining-Analytics
Python project for data cleaning, EDA, and charts. NLP extracts keywords, entities and tags to classify issues; TF-IDF and K-Means reveal clusters, failure trends and root-cause clues. Uses Pandas, NumPy, Matplotlib, Seaborn, NLTK, spaCy and Scikit-learn. Outputs cleaned data, charts and Excel/CSV reports for product quality and business decisions.
